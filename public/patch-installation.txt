SAKURA NO UTA — MAO ENGLISH PATCH v1.1.2
Dancing above the Cherry Forest

Website and bilingual reader: https://mao-tls.github.io/sakura-no-uta/

SUPPORTED EDITION
Japanese Sakura no Uta Re:Graphic 10th Anniversary edition, Ver1.0.0.
The installed game must contain sakuranouta10th.exe and its original
sakuranouta10th.pfs archives, including sakuranouta10th.pfs.500.
This patch is not for the original 2015 edition, Sakura no Toki, or another
publisher's English edition. You need your own legally acquired game.

WHAT IS INCLUDED
The complete English script, localized text images and interface text:
285 scripts, 65,164 lines, 137 images, and 221 interface strings.
The ZIP contains the translation overlay, an English-subtitled opening
movie, and these instructions. It does not include the complete game,
its executable, dialogue voices, or a Wine runtime.

INSTALL ON WINDOWS
1. Close the game and extract this ZIP.
2. Open the installed game folder containing sakuranouta10th.exe.
3. If that folder already contains sakuranouta10th.pfs.502, move that file
   to a backup folder outside the game folder before proceeding. Preserve
   any earlier patch you may want to restore.
4. Copy the supplied sakuranouta10th.pfs.502 into the game folder, alongside
   the executable and original archives. Keep its exact filename.
5. Copy the ZIP's movie folder into the game folder. It adds
   movie/ou9nq3hr2_mao.mp4; do not rename or replace the original movie.
6. Launch sakuranouta10th.exe normally.

Do not replace or remove the original .pfs, .000, .001, .002, .003, or .500
archives. No installer, Python, administrator access, or font installation
is required to apply this patch. Copy the .502 and the supplied movie folder.

MACOS / WINE
Install into the same game folder used by your existing Wine launcher,
then fully quit and relaunch the game through that launcher. If the game
is stored inside a Wine prefix or bottle, open that location first.
The patch does not configure Wine or change your existing launcher.
The v1.1.0 engine passed targeted checks in a private macOS Wine copy:
the reported passage in all three fonts, multi-page dialogue and backlog,
history jumps, continuation-page quick saves/loads, font changes, long
speaker labels, and five encountered characters' voice controls.
This update corrects a source-audio-verified surname, recovers encountered
characters' voice controls from the original read-history markers, and
clears stale hidden measuring text restored by older saves. Targeted private
Wine checks do not constitute a new native Windows or whole-game playthrough.
KNOWN MOVIE ISSUE: the opening displays a blank/white picture in the tested
macOS Sikarugir Wine wrapper. Movie playback in that wrapper is not fixed.
Native Windows movie playback, sound, subtitles and return to the game
have not been verified. Do not treat this release as a verified Wine
movie-playback fix. Keep your previous patch backup if this blocks you.
Native Windows, other Wine configurations, compatibility with every
existing save, and a manual start-to-finish playthrough are not verified.
There is no standalone Mac application in this download.

UPDATE
Close the game. Back up the installed sakuranouta10th.pfs.502 outside the
game folder and replace it with the newer release's file. Keep exactly
one file with that name. Also copy the supplied movie folder, replacing
only an earlier MAO ou9nq3hr2_mao.mp4 if present. Relaunch the game.

REMOVE / RETURN TO JAPANESE
Close the game and move the MAO sakuranouta10th.pfs.502 out of the game
folder. If you backed up a pre-existing file with that exact name, restore
it. Launch again. The original game archives and save files are untouched
by this installation procedure. Back up your saves before switching patches.
The added movie/ou9nq3hr2_mao.mp4 may also be removed; leave the original
movie/ou9nq3hr2.wmv untouched.
If an already-open text page retains old text after loading, advance to
the next page or start a new game to check the currently installed patch.

TROUBLESHOOTING
Still Japanese: confirm that the file is beside sakuranouta10th.exe, not
inside an extra extracted folder. Check for a hidden duplicate extension.
Fully quit the game before relaunching. Check that your launcher opens
this same installation, and temporarily remove other unofficial patches.

Broken wrapping or unexpected old text: confirm the patch checksum below,
then restart. This release contains English word wrapping, punctuation
attachment, baseline ellipses, and the leading-space correction.

Individual voice controls all showing Unknown after meeting characters:
v1.1.0 corrected the internal unlock keys. This update also recovers missing
unlocks when read history proves the original unlock point was completed.
Open Config > Sound after updating. Unseen characters remain Unknown;
volume and mute settings are preserved. Fully quit and relaunch after
updating. Check the .502 checksum and
that your launcher uses the folder you updated. Do not delete your save
or system-data files: they contain progress and unlock information.
If the problem persists, report the patch checksum and operating system;
include your save and system-data files privately if you can.

Long text skips its continuation: this remains an unconfirmed report on a
player's installation; do not treat this update as a verified fix for it.
Check the patch checksum and temporarily move third-party language-toggle
or other unofficial patches outside the game folder, keeping backups.
If it persists, provide the affected save, system-data files, operating
system, font setting, and installed patch filenames for reproduction.

Skipping unread text: holding Ctrl is the original game's force-skip
control. For read-only skipping, select Config > Text > Skip text > Read
only and use the on-screen Skip button instead. If that button skips
unread text with Read only selected, report that separately from Ctrl.

Game will not start: move this .502 out of the game folder and try the
unmodified game. If it also fails, check the original installation or
Wine configuration. Restore your previous .502 backup if needed.
